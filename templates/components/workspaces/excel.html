Nhập liệu điện 3 giá

Nhập dữ liệu điện theo kỳ/tháng, lưu file dữ liệu để tiếp tục bất kỳ lúc nào, và xuất bảng tổng hợp tiêu thụ 12 tháng chuyên nghiệp.

📖 Hướng dẫn chi tiết & Cấu trúc file dữ liệu / hóa đơn (Click để xem)
📊 1. Cấu trúc File Excel dữ liệu (.xlsx) lưu giữa chừng:
• Tên Sheet chuẩn: DuLieu
• Cấu trúc 11 cột chuẩn:
nam thang ky thue_vat bt_don_gia bt_san_luong cd_don_gia cd_san_luong td_don_gia td_san_luong ghi_chu
- nam, thang, ky: Năm (2024, 2025), Tháng (1-12), Kỳ (1-3).
- thue_vat: Thuế suất VAT (%) áp dụng cho kỳ (VD: 0, 8, 10).
- bt_*, cd_*, td_*: Đơn giá (đ/kWh) và Sản lượng tiêu thụ (kWh) theo 3 khung giờ Bình thường, Cao điểm, Thấp điểm.
- ghi_chu: Ghi chú hoặc tên file hóa đơn gốc.
💡 Lưu ý: File dữ liệu dạng bảng phẳng (flat table) này giúp bạn có thể tải về lưu trên máy, lần sau bấm "Nạp file có sẵn (.xlsx)" để nhập tiếp mà không bị mất dữ liệu.
⚡ 2. Hướng dẫn file hóa đơn điện tử (ZIP / PDF dạng vector):
• Định dạng chấp nhận: File .zip hoặc chọn nhiều file .pdf tải về từ cổng thông tin EVN (EVNSPC, EVNHCMC, EVNHANOI, EVNNPC, EVNCPC...).
• Hỗ trợ ZIP lồng ZIP: Bạn có thể gom tất cả các file ZIP tải về từ EVN (ví dụ: 1-1-24.zip, 2-1-24.zip, 3-1-24.zip...) vào 1 file ZIP lớn và nạp tự động.
• Hóa đơn PDF scan (dạng ảnh): Với file PDF scan, vui lòng sử dụng Tool Desktop OCR (.exe) để OCR và xuất file .txt, sau đó dùng nút "📄 Nạp file Text (.txt / OCR)".
• File chi tiết ưu tiên: Hệ thống tự động tìm và đọc các file PDF bảng kê chi tiết có đuôi _CTIET.pdf, _CT.pdf hoặc file hóa đơn chuẩn.
📄 3. Hướng dẫn nạp file Text (.txt) từ Tool OCR Desktop:
• Quy trình tối ưu tài nguyên: Sử dụng ứng dụng Tool Desktop OCR (.exe) để OCR hàng loạt ảnh/PDF hóa đơn trực tiếp trên máy cá nhân mà không làm tốn tài nguyên server.
• Nạp dữ liệu tự động: Bấm nút "📄 Nạp file Text (.txt / OCR)" và chọn file .txt vừa xuất ra từ tool desktop.
• Nhận diện thông minh: Hệ thống tự động bóc tách chuẩn xác toàn bộ các kỳ, tháng, năm, 3 mức đơn giá & sản lượng (Bình thường, Cao điểm, Thấp điểm), thuế VAT (%) và mã từng trạm công tơ mà không bị ghi đè dữ liệu.
✍️ 4. Hướng dẫn nhập tay nhanh (Chuỗi / Từng ô):
• Nhập bằng chuỗi: Copy & dán 3 dòng (Bình thường, Cao điểm, Thấp điểm) từ bảng thông báo tiền điện theo mẫu <Đơn giá> <Sản lượng> (VD:
  1.833 51.559
  3.398 19.180
  1.190 28.653)
• Nhập từng ô: Bạn có thể copy 3 dòng số liệu và dán trực tiếp vào ô Đơn giá BT, hệ thống sẽ tự động phân tách và điền đủ 6 ô còn lại.
